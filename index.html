      Connect this device

      This device is connected
      Setting up a new key (for the person who manages it)
      1. Sign in at console.anthropic.com and add credit.
      2. Under Limits, set a monthly spend limit.
      3. Under API keys, create a key and copy it.
      4. Paste it above and press Save and test.

      A setup link connects a device in one tap and then removes itself from the address bar. Anyone who has the link can use the key, so send it privately and delete the message afterwards.

      Symphony’s human voice optional

      Add a voice key and Symphony speaks with a natural human voice, on this device and on every device you set up with a personal link. Without it she uses this device’s own voice.

      Human voice on
      Getting a voice key (for the person who manages it)
      1. Sign in at platform.openai.com and add a little credit. Her voice costs about 1.5 US cents for each minute she speaks, and each sentence is kept on the device, so repeats are free.
      2. Set a monthly budget under Limits.
      3. Under API keys, create a secret key and copy it.
      4. Paste it above and press Save and test. Then copy fresh personal links for your teachers from the dashboard, so their devices get her voice too.
